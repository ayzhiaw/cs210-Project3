# cs210-Project3
This is a C++ program that reads grocery items from a file, tracks how many times each item appears, and stores the counts in a backup file.

1. Summarize the project and what problem it was solving.
My project was a Grocery Item Tracking Program that reads grocery items from a file and counts how many times each item appears. It allows users to look up items, see how often each item was purchased, and view a histogram. This makes it easier to keep track of grocery purchases without counting everything by hand.

2. What did you do particularly well?
I think I did a good job organizing my code into different functions so everything was easier to understand. I also used a map to keep track of how many times each grocery item appeared. I am proud that I was able to create a menu that lets users choose what they want to see.

3. Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?
I could improve my code by adding better error handling if the input file is missing or the user enters something invalid. I could also make the search work even if someone types an item with different capitalization. These changes would make the program easier to use and help prevent errors.

4. Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?
One of the most challenging parts was figuring out how to count the grocery items using a map and save the results to a file. I worked through it by reviewing my code, adding comments, and breaking the program into smaller parts. In the future, I can use my class notes, C++ documentation, and help from my instructor or classmates when I need it.

5. What skills from this project will be particularly transferable to other projects or course work?
This project helped me practice using classes, functions, maps, loops, and files in C++. These skills will help me with future programming assignments and projects that involve organizing information. I also learned how to make a program easier for users to navigate.

6. How did you make this program maintainable, readable, and adaptable?
I made my code easier to read by using comments, clear function names, and separate functions for different tasks. I also separated my code into a header file, an implementation file, and a main file to keep everything organized. This makes it easier to fix problems or add new features later without changing the whole program.
